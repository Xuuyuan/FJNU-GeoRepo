# 软件工程与GIS设计

GIS专业-专业主干必修课，分为两门课程：《软件工程与GIS设计》（2学分）、《软件工程与GIS设计实验》（1学分），给分相同。分数占比为：实验60%、期末开卷40%。期末开卷考试，需要打印资料。部分题目需要结合自己小组作业进行作答。本门课程的小组作业与《GIS应用开发方法》共用。
