# 师大快跑 MVP 验收清单

本文档用于微信开发者工具和真机验收。每次上传演示版本前，先完成自动检查，再完成能执行的手工项。

## 1. 自动检查

- 在项目根目录运行 `npm test`。
- 在项目根目录运行 `npm run check:js`。
- 确认没有未预期的本地改动混入本次验收版本。

## 2. 微信开发者工具

- 重新上传部署云函数 `sdkpFunctions`。
- 确认云开发环境为 `cloudbase-5geu96mj1eb64ee8`。
- 重新编译小程序，首页无组件路径、权限声明或基础库报错。
- 打开首页后，控制台可看到或可确认以下调用成功：
  - `getRuntimeConfig`
  - `getUserProgress`
  - `initUserProfile`
- 留空 `poi_config/current` 时，小程序继续使用本地 POI 与 quiz 配置。
- 写入 `poi_config/current` 的 POI 名称或 quiz 文案后，首页和图鉴可读取云端文案覆盖。

- 首次打开小程序，完成定位授权。
- 点击“开始探索”，确认 GPS 状态变为连接中或已连接。
- 校园内移动至少 3 分钟，记录：

- 行走经过至少一个 POI，确认出现“发现地标”或 quiz 弹窗。
- 对 quiz 型 POI 先答错一次，确认不会计入发现；再答对一次，确认计入发现。
- 点击“结束探索”，确认进入结算页，并记录：
  - 本次距离：
  - 探索时长：

- 返回地图后点击“立即同步”，确认云端同步成功或出现明确失败提示。

## 4. 云数据库核对

在云开发控制台核对以下集合：

- `userinfo`：当前用户 `total_grids`、`explore_ratio` 已更新。
- `gridstatus`：新增用户-网格记录，重复同步不会产生重复文档。
- `poi_records`：答题通过或 touch 触发的 POI 已写入。
- `track_sessions`：本次探索会话已写入，距离、时长、网格数与结算页大体一致。

## 5. 重新打开恢复

- 关闭并重新打开小程序。
- 首页累计点亮网格和覆盖率可恢复。
- 历史页可看到最新探索会话。
- POI 图鉴可看到刚发现的地标。
