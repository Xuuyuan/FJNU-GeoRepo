# 软件工程与GIS设计

[@Xuuyuan](https://github.com/Xuuyuan)

本目录下内容是本人于2025-2026学年第2学期修读《软件工程与GIS设计》时完成的小组作业项目的过程性资料及最终资料，仅作留档参考。本人得分为 90.2 分（19/65），小组其它成员得分分别为 A-97.0、B-95.5、C-93.4、D-75.7、E-67.5。

项目代码主要由本人使用 GPT-5.5 完成，A、D参与了部分代码的补充、修改及方案调整，过程性文档由本人完成、课程汇报及汇报PPT制作主要由C完成。

最终汇报PPT中关于名字的第一页因为涉及个人信息被删去。经验如下：最终汇报会持续很长时间（我们汇报是最后一组，下午两点开始汇报、接近晚上七点才轮到我们，平均每组二十分钟左右，所以排序在后面的可以晚一些去实验室）。由于很多小组所使用的PPT都是AI生成，务必注意字体问题（不处理字体有显示乱码的可能性）。我们小组汇报PPT采用了GPT生图-图转PPT的方案，相对千篇一律的PPT而言会更加美观，这也是我认为部分小组成员高分的原因之一（老师有特别提到这一点）。此外，有小组采用软硬件结合的方式完成项目，因此也获得了极高的分数。
