# 廷坪乡地质灾害风险评估 WebGIS

一个基于 `Vite + React + TypeScript + Leaflet` 的 WebGIS 原型系统，用于展示福建省福州市闽侯县廷坪乡地质灾害风险评估成果。项目以村级综合风险表达为主线，结合隐患点、200 米缓冲区、受威胁建筑和村委员会定位点，实现课程汇报、成果演示和静态部署场景下的可视化表达。

## 项目定位

本项目重点不在于在线重算模型，而在于将已经完成的风险评估成果组织成一个可运行、可交互、可展示的前端原型系统。

- 主表达对象：村级综合风险面
- 辅助解释对象：隐患点与 200 米缓冲区
- 影响对象表达：受威胁建筑图斑
- 辅助定位对象：村委员会定位点
- 特殊说明对象：争议地区域

当前版本适合：

- 课程汇报与成果展示
- 本地原型演示
- 构建后的静态站点部署

## 功能概览

- 加载本地 GeoJSON 数据并自动定位到研究区范围
- 以村级综合风险等级作为主专题图层进行着色表达
- 支持图层开关：村级风险、争议地、隐患点、建筑、村点
- 支持专题检索，可搜索村庄和隐患点
- 支持风险等级与隐患类型筛选
- 点击村面查看综合风险、暴露度、承灾能力等属性
- 点击隐患点联动显示对应缓冲区及受威胁建筑信息
- 点击建筑查看是否为受威胁建筑及关联隐患信息
- 提供图例、统计摘要、缩放控制和加载异常提示

## 数据图层说明

项目当前围绕 `public/data/` 下 6 个业务图层展开：

| 文件名 | 作用 |
| --- | --- |
| `village_polygon_web.geojson` | 村级综合风险主图层 |
| `vill_pt_web.geojson` | 村委员会定位点辅助查询图层 |
| `hazard_points_web.geojson` | 隐患点图层 |
| `haz_buffer_200m_web.geojson` | 隐患点 200 米缓冲区图层 |
| `building_poly_web.geojson` | 建筑图斑与受威胁建筑表达 |
| `village_dispute_web.geojson` | 争议地说明层 |

数据使用约定：

- 格式：`GeoJSON`
- 坐标系：`WGS 1984 / EPSG:4326`
- 加载方式：前端通过相对路径静态读取
- 当前版本不依赖后端数据库或 GeoServer

## 本地运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发环境

```bash
npm run dev
```

默认会启动 Vite 本地开发服务。

### 3. 生产构建

```bash
npm run build
```

构建脚本会先执行 TypeScript 类型检查，再输出静态资源。

### 4. 本地预览构建结果

```bash
npm run preview
```

## 当前界面逻辑

系统采用三栏式布局：

- 左侧：图层控制、筛选和统计摘要
- 中间：地图主视图
- 右侧：对象详情与网页介绍

主要交互逻辑如下：

- 点击村级面：查看村名、风险等级、暴露度、承灾能力、风险值等信息
- 点击隐患点：查看隐患属性，并联动高亮对应缓冲区
- 点击建筑：查看建筑编号、威胁状态及关联隐患
- 点击村点：辅助定位和补充查询
- 搜索对象：将地图快速聚焦到对应村庄或隐患点
