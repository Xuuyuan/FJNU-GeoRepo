# 遥感数字图像处理

本目录收录福建师范大学地理信息科学专业《遥感数字图像处理》课程的实验、复习和软件操作资料。课程使用 PCI Geomatica，教材可参考《遥感数字图像处理（第三版）》（章孝灿、苏程等，浙江大学出版社）。

> 资料来自不同学年，教学内容、软件版本和考核方式可能变化。请以当学期教师要求为准；历年作业适合了解结构与操作思路，不建议直接照搬。

## 第一次使用

建议按下面的顺序查阅：

1. 初学 PCI Geomatica：阅读 [软件与数据](#软件与数据)。
2. 准备实验：先看对应学年的操作讲解，再参考个人作业的结构。
3. 准备期末：先看近期真题，按题型回到教材和课堂笔记复习。
4. 需要补概念：查看 [知识主线](#知识主线) 和历年复习资料。

## 知识主线

课程内容大致可以整理成六部分：

| 模块 | 应掌握的内容 |
| --- | --- |
| 遥感影像基础 | 像元、灰度、亮度、位深度，空间/光谱/时间/辐射分辨率 |
| 波段与显示 | 波段、通道、真彩色、假彩色、直方图和显示拉伸 |
| 影像预处理 | 辐射定标、大气校正、几何校正、正射校正、重采样 |
| 影像增强与变换 | 反差增强、空间滤波、PCA、IHS、影像融合 |
| 信息提取 | 监督分类、非监督分类、训练样本、分类后处理和精度评价 |
| 综合应用 | 变化检测、元数据判读、软件操作流程设计 |

## 资料维护建议

- 文件名使用“学年 + 内容 + 类型”，例如 `2026-2027学年实验一操作.pdf`。
- 原始数据、操作说明、作业样例和复习材料分开存放。

- 新增资料时同步更新本 README，写明学年、来源和适用范围。
