## 学习方法

每次实验都建议记录四项内容：

1. 输入数据是什么，包含哪些波段或辅助文件；
2. 使用了哪个工具，关键参数是什么；
3. 输出数据的坐标系、分辨率、波段顺序和数据类型；
4. 如何检查结果是否正确。

软件界面会随版本变化，因此应优先理解“输入—处理—输出—检查”的逻辑，再记按钮位置。
